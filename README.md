# AI-Research-paper-explainer
An AI-powered web application that helps users understand research papers easily. The system allows users to upload a research paper PDF and automatically generates a simplified explanation . It extracts the paper’s content, stores embeddings in a vector database, and uses a LLM to provide summaries and generate questions for better understanding.

# Features

-Upload research paper PDFs 

-Automatic paper summarization

-Key contribution extraction

-Mathematical concept explanations

-AI-generated questions for learning

-Semantic search using vector embeddings

# Tech Stack

Frontend:React

Backend:Python,FastAPI

AI / ML:LangChain,Retrieval-Augmented Generation (RAG),LLM API

Database:Vector database (Chroma)

Document Processing:PyPDF
